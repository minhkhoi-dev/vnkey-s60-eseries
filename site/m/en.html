VnKey Vietnamese Telex typing in every app on the Nokia E72
Download VnKey (.sisx) Needs a hacked phone (InstallServer and Open4All patches).

Install

  1. Download the .sisx above and install it to the phone memory (C:).
  2. Open VnKey and set Telex mọi ứng dụng (Telex in all apps) to Bật (On).
  3. In Messaging, type Vieejt and a space: you get Việt.
  4. Ctrl+Space switches Vietnamese / English. A [V] or [E] shows in the bottom bar.

Telex

aaâsá sắc
awăfà huyền
eeêrả hỏi
ooôxã ngã
owơjạ nặng
uw, wưzno tone
ddđ
Marks and tones can also come at the end of the word: toans -> toán, nguoiwf -> người. Press twice to undo: ass -> as.

Features

  • Works in every app: Messaging, the browser, chat.
  • English words stay English: tẽt -> text.
  • Shortcuts: ko -> không, dc -> được (edit macros.txt).
  • Traditional (hòa) or modern (hoà) tone placement.
  • Starts with the phone. Screens in Vietnamese or English.

Good to know

  • Turning it off: set Telex in all apps to Off, answer No, then restart the phone.
  • Updating, removing: turn it off as above and restart first.
  • Emergency off: make a folder off in E:\VnKey\
  • Privacy: the log stays on the phone (E:\VnKey\vnkey.log); nothing is sent anywhere.
  • Download fails? The S60 browser only has TLS 1.0 and GitHub needs TLS 1.2. Install the TLS patch (nnproject.cc/tls), or download on a computer and copy the file to the phone.
